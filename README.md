# Hariprasanth T — Minimalist Developer Portfolio (Pure HTML & CSS)

Personal portfolio for **Hariprasanth T**, third-year Computer Science & Engineering undergraduate at VSB College of Engineering & Technical Campus, Coimbatore.

Built with **100% pure HTML5 & CSS3 (zero JavaScript)** in an editorial Swiss minimalist aesthetic using the bundled **SF Pro** sans-serif typeface family.

## Highlights
- **Zero JavaScript**: Pure semantic HTML5 & modern CSS3 — no scripts, no build tools, no dependencies.
- **Typography**: Local `SF Pro Display` & `SF Pro Text` (`@font-face`, `font-display: swap`).
- **Pure CSS Dual Theme**: Studio Light default with a CSS-only Matte Dark toggle (`:root:has(#theme-toggle:checked)`).
- **Pure CSS Project Filter**: Filter `APIForesight`, `Digi Bus`, `RemindGo`, and `SysScan` using native radio inputs & CSS `:has()`.
- **Native PDF Links**: Direct view & download links for Resume, Emertxe Certificate & Offer Letter, IBM Coursera Certificate, and Deloitte Certificate.

## Local Preview
Open `index.html` directly or run any static file server:

```bash
python -m http.server 8080
```

## Deploying to GitHub Pages (`ihariprasanth.github.io`)
Push the contents of this folder straight to the `main` branch of your GitHub repository and enable GitHub Pages.
